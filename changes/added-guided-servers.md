- `pakem setup` also sets up the servers a device releases to. On a terminal it offers each
  recorded server and new ones, and runs `pakem setup host` for each in the owner's own
  terminal and login: the release engine installed or updated, and this device's key
  allowed for the server's projects. `--server NAME_OR_TARGET` names them without asking. A
  server that fails is named with the command to run again, and the rest of the setup
  completes.
