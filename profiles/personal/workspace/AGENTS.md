# Personal workspace

The owner's framework kernel is installed globally, and each project pins its profile;
this file only maps this workspace.

- `enrico/` holds personal projects (profile `personal`). `freelance/` and the client
  folders hold client work (profile `freelance`). Archived client folders (development
  held by the client) are read-only reference.
- `private/` and `tests/` are outdated: never use them as references or templates.
- A sibling named `<repo>-<topic>` may be a worktree of `<repo>`; work only in the
  checkout you were given.
- Commercial records stay in the `pakem docs` store (`freelance/documents/`), never in
  a code repository.
- Dormant projects need no `AGENTS.md`; add one when a project becomes active.
