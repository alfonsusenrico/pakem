Team project rules (Pakem profile `example`):

- Repositories live in the team's GitHub organization, private unless the team lead
  makes one public. Checks run on GitHub-hosted runners within the plan's minutes.
- Use only the services on the team's approved tools list (`default:approved-tools`).
  Propose another with its monthly cost and what it replaces; the team lead decides.
- Another engineer reviews and merges each pull request.
- Code, docs, and commits are in English; each project states the language of its UI
  and generated content.
- Commit with your own name and work email. Automation uses the team's bot account,
  never a person's token.
