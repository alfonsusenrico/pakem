# Design Bases

Status: Active
Applies to: projects that adopt a named design base
Last reviewed: 2026-10-07
Review by: 2027-04-07
Sources: owner Working Standard Profile section 8

A design base is a concrete starting point (tokens and component character) for a
surface. A project adopts one by writing `Design base: <name>` in `AGENTS.md` and
copying its tokens into the project's tokens file, then adapting the accent and type
to the product.

Each base file states: surface, tokens (colour roles with values for light and dark,
type pairing and scale, radii, shadows, motion), component character, and do/don't.

Available bases:
- `owner-studio` (`owner-studio.md`) - marketing and portfolio surface, from the owner's
  approved portfolio (2026-10).

Bases for tools (dashboards, workbenches) will be added from the owner's private
reference.
